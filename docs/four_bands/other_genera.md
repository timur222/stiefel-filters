# Что означает род для четырёх полос

В исходной статье задача трёхполосная. Для одних и тех же знаков полос выбор концов и топологического класса меняет семейство решений. Во введении и на рис. 6 авторы указывают три варианта: дроби Золотарёва рода 1, дроби Стифеля рода 2 и решения рода 3. Скалярный период τ относится к внешней эллиптической функции. Внутренняя кривая у дробей Стифеля имеет собственную матрицу периодов. [Статья, §§ 1.3 и 3.2](https://arxiv.org/html/2611.17372v1).

## Проверяемый критерий рода

Пусть известна несократимая рациональная функция r степени n, её равномерная ошибка равна 0 < μ < 1. Положим V = {−1−μ, −1+μ, 1−μ, 1+μ}. Над комплексной проективной прямой нормализуем двойное накрытие

```math
y^2=\prod_{v\in V}(r(x)-v).
```

Каждая точка x над v ∈ V с нечётной локальной степенью становится точкой ветвления, включая x = ∞, если она попадает в такой слой. Полюса r имеют чётный порядок в правой части. Если B — число точек ветвления, формула Римана–Гурвица даёт g = (B−2)/2. Накрытие имеет непостоянное отображение на эллиптическую кривую с координатами (r,y), поэтому g ≥ 1. Это способ определить род по точным коэффициентам дроби и μ. При плавающей точке близкие корни требуют дополнительной проверки кратностей. [А. Б. Богатырёв, Chebyshev representation for rational functions](https://www.inm.ras.ru/wp-content/uploads/library/Comp-Tech/BOGA11SE.pdf).

Для четырёх полос можно вывести условную верхнюю границу. Предположим, что решение полной степени n обладает обычным альтернансом из 2n+2 точек. Среди них максимум восемь концов полос. Остальные — внутренние экстремумы с чётной локальной степенью не менее двух. Суммарная кратность четырёх слоёв равна 4n. Каждый из этих экстремумов уменьшает число нечётных прообразов по меньшей мере на два. Следовательно, B ≤ 4n−2 max(0,2n−6) ≤ 12 и g ≤ 5. Пример ниже достигает верхней границы g = 5. Вырожденные решения и задачи с другим условием чередования требуют своего подсчёта.

## Явное семейство рода 1 для четырёх заданных интервалов

Пусть E₁ соответствует −1, а E₂, E₃, E₄ соответствуют +1. Временно заполним два промежутка между положительными интервалами. Четыре конца оставшихся двух интервалов A < B < C < D вещественная дробно-линейная замена w приводит к −1, −q, q, 1 соответственно. Параметр q определяется двойным отношением:

```math
s=\sqrt{\frac{(B-A)(D-C)}{(C-A)(D-B)}},\qquad
q=\frac{1-s}{1+s},\qquad
H=\frac{K(\sqrt{1-q^2})}{K(q)},\qquad \tau=iH/n .
```

Здесь K принимает эллиптический модуль. Пусть X(u|τ) обозначает эллиптическую синусоиду из (4) статьи. Решаем w = q X(u|nτ) и подставляем u во внешнюю X(u|τ), с той же нормировкой прямой и обратной дробей, что в статье. Внутренняя кривая здесь задана четырьмя точками ветвления ±1, ±q. Обратный эллиптический интеграл считается дупликацией симметрического интеграла Карлсона. [Предельный случай без разреза, § 3.1](https://arxiv.org/html/2611.17372v1#S3.SS1).

На каждом из двух полных интервалов имеется n+1 экстремумов. На правой стороне прямоугольника их высоты равны j Im τ при j = 0,…,n. Если оба удалённых **открытых** промежутка не содержат ни одного из этих экстремумов, то на четырёх полосах остаются все 2n+2 чередующихся значения ±μ и данная дробь сохраняет локальную оптимальность. Действительно, у близкого строго лучшего конкурента разность значений меняла бы знак 2n+1 раз на упорядоченных точках. Произведение знаменателей в каждой из точек положительно после согласованной нормировки, а числитель разности имеет степень не выше 2n.

Для проверки промежутка достаточно перевести левый конец в координату высоты и проверить следующий целый уровень. В реализации проверяются также соседние уровни для учёта округления. Число таких проверок независимо от n. Проверка охватывает конкретный выбор двух исходных полос. Если экстремум попадает в промежуток, функция сообщает его номер.

```julia
using StiefelFourBands

f = zolotarev_fourbands(0.7im, 2; gaps=((0.2,0.4),(1.6,1.8)))
g = zolotarev_fourbands(f.endpoints, 2)
plot_filter("genus-one.html", g)
```

Для независимой проверки в симметричной нормировке и степени 2 обратная дробь имеет элементарный вид r*(x) = 2(x+q/x)/(1+√q)². Тесты сравнивают эту формулу с эллиптической реализацией на вещественной оси и в комплексной плоскости, проверяют проективную ковариантность и вычисление при степени 3000.

## Четыре полосы с кривой рода 4

Пусть F(x) = x − 9/(x+1) + 2/(x−1) и R(x) = F(x) − 2 − μ. Тождество

```math
F(x)-1=\frac{(x+3)(x-2)^2}{x^2-1}
```

определяет слой R = −1−μ: при x = −3 этот уровень достигается с кратностью один, при x = 2 — с кратностью два. Для каждого значения y > 1 уравнение F(x) = y имеет три простых корня. Действительно, хотя бы по одному корню лежит в (−3,−1), (1,2), (2,∞) по знакам функции на концах, а степень кубического уравнения равна трём. Обозначим эти корни через A(y), B(y), C(y) соответственно. Функции A, C возрастают, B убывает, поскольку на каждом из этих промежутков соответствующий корень единствен и непрерывно зависит от y.

Полосу подавления берём между B(1+2μ) и C(1+2μ). Точка касания x = 2 находится внутри неё. Три полосы пропускания получаем как полные прообразы F ∈ [3,3+2μ]. Для выбора первой полосы и перехода к конечным координатам используем w = −1/(x−c), где c = B(2+μ) лежит в промежутке между полосами и R(c) = 0. Упорядоченные по w полосы соответствуют полосе подавления и положительным ветвям C, A, B. В этих координатах w = 0 — полюс дроби в зазоре. Все восемь концов конечны.

На полосе подавления значения ошибки на левом конце, в точке касания и на правом конце равны (+μ,−μ,+μ). На следующих трёх полосах ошибки на парах концов равны (−μ,+μ), (−μ,+μ), (+μ,−μ). Пропуск левого конца последней полосы оставляет восемь чередующихся точек, что даёт локальную оптимальность при n=3. Для обратной дроби (1−μ²)/R те же точки дают противоположные знаки. Три слоя над оставшимися уровнями содержат девять простых точек. Вместе с x = −3 получается B = 10 и g = 4. В `folded_fourbands(τ)` все десять точек доступны в поле `branchpoints`, заданном в координате w. Программа поддерживает три дополнительных параметра формы. В координате x используется

```math
R(x)=-1-\mu + a\,\frac{(x-t)^2(x-d)}{x^2-1},\qquad a>0,\quad t>1,\quad d<-1 .
```

Значения по умолчанию a = 1, t = 2, d = −3 дают выписанный выше пример. Слой −1−μ содержит простой корень d и двойной корень t. У каждого из трёх более высоких уровней есть по одному простому прообразу в каждом из интервалов (d,−1), (1,t), (t,∞). Тот же выбор обратных образов даёт четыре полосы и восемь чередующихся экстремумов. `folded_period_matrix` вычисляет Ω по десяти простым прообразам в координате w; циклы a берутся над вторым, четвёртым, шестым и восьмым промежутками между соседними точками ветвления. `folded_from_periods` подбирает a,t,d по десяти независимым элементам заданной Ω либо Π = iΩ. Приёмка требует согласования всех элементов на двух порядках квадратуры с относительной нормировкой max(0.1, |Ωᵢⱼ|) до 10⁻⁸. Это локальное численное обращение для данной размеченной кубической семьи.

```julia
h4 = folded_fourbands(0.7im; scale=1.25, turning=1.7, odd_root=-2.4)
Ω4 = folded_period_matrix(h4)
restored = folded_from_periods(0.7im, Ω4)
plot_filter("genus-four.html", restored)
```

## Четыре полосы с кривой рода 5

Рассмотрим дробь степени 3

```math
r(x)=x-\frac1{x+1}-\frac1{x-1}=\frac{x^3-3x}{x^2-1}.
```

Её производная строго положительна на трёх ветвях (−∞,−1), (−1,1), (1,∞). На каждой ветви функция возрастает от −∞ до +∞. Зададим μ ∈ (0,1). На первой ветви возьмём прообраз [−1−μ,−1+μ] как полосу подавления. В качестве трёх полос пропускания возьмём три прообраза [1−μ,1+μ], по одному на каждой ветви.

На восьми концах полос ошибка r−S принимает значения −μ,+μ попеременно. Внутри каждой полосы она строго между этими уровнями. Все восемь концов нужны для альтернанса 2n+2. Следовательно, та же оценка степенью числителя разности доказывает локальную оптимальность, а у r* = (1−μ²)/r знаки в альтернансе меняются на противоположные. У каждого из четырёх уровней по три различных простых прообраза. Таким образом, B = 12 и g = 5 в точности. В частности, четыре дополнительные точки ветвления лежат вне концов выбранных рабочих полос. Этот пример получен прямым построением.

Функция `pick_fourbands` реализует тот же аргумент для r(x) = x + c − A/(x−a) − B/(x−b) при a < b и A,B > 0. По τ вычисляется μ, а обратные образы каждого из четырёх уровней находятся как собственные значения симметричной матрицы 3×3. Внутренняя матрица периодов определяется кривой, восстановленной по двенадцати прообразам. Для построения графика достаточно явной рациональной формулы.

```julia
h = pick_fourbands(0.7im; poles=(-1.,1.), residues=(1.,1.), offset=0.)
plot_filter("genus-five.html", h)
```

Для произвольных восьми упорядоченных концов и степени 3 прямое обращение рациональной формулы описано отдельно. [Кубическая дробь по заданным полосам](cubic.md).

## Как исследовать остальные конфигурации

Универсальная постановка для конечных замкнутых полос не требует заранее выбирать род. Она полезна как независимый ориентир для новых формул, особенно при умеренном n. Ниже дана математическая постановка общего решателя. Реализованные в Julia прямые формулы описаны выше и в README.

1. Для фиксированного пробного ε ∈ [0,1] запишем r = P/Q с вещественными полиномами степеней ≤ n. Переберём знаки sⱼ знаменателя на четырёх полосах с точностью до общего знака (восемь вариантов). В каждом варианте потребуем на всей полосе j с целевым уровнем Sⱼ, чтобы sⱼ Q ≥ 1, sⱼ[P−(Sⱼ−ε)Q] ≥ 0 и sⱼ[(Sⱼ+ε)Q−P] ≥ 0. Любой знаменатель без полюсов на полосах допускает общую нормировку первого неравенства.
2. При фиксированных ε и s эти неравенства линейны по коэффициентам P и Q. Каждое условие неотрицательности на интервале [a,b] имеет точное конечномерное представление. Для полинома степени ≤ 2d используется сумма квадратов плюс (x−a)(b−x), умноженное на сумму квадратов (степени квадратных корней ≤ d и d−1). При ограничении ≤ 2d+1 используются суммы квадратов степеней корней ≤ d с весами (x−a) и (b−x). Согласование коэффициентов с положительно полуопределёнными матрицами Грама даёт задачу полуопределённой допустимости. [Представление полиномов, неотрицательных на интервале](https://link.springer.com/article/10.1007/s10013-024-00700-3).
3. Бисекция по ε приближает инфимум ошибки среди всех классов: допустимость хотя бы в одном варианте даёт верхнюю границу, доказанная недопустимость во всех восьми — нижнюю. При вычислении в плавающей точке достоверность каждой границы зависит от проверки соответствующего сертификата. Этот перебор ориентирован на глобальную задачу со свободным классом. Чтобы выделить заданный пользователем топологический класс, необходимо дополнительно контролировать чётности нулей в промежутках. Размеры матриц Грама растут с n.
4. Полученный кандидат позволяет изучать уровни V, их прообразы, кратности и род. Для нового семейства уже после такого исследования можно искать низкоразмерное представление через периоды и сравнивать результаты с независимой оптимизацией.
