# Дробь степени 3 по любым четырём полосам с целями −,+,+,+

Пусть восемь вещественных чисел строго упорядочены, полоса подавления равна [e₁,e₂], три полосы пропускания равны [e₃,e₄], [e₅,e₆], [e₇,e₈]. Следующие формулы дают один локальный минимум в равномерной норме. Они выведены для этой четырёхполосной задачи.

Обозначим a=(e₃,e₅,e₇), b=(e₄,e₆,e₈), A(x)=∏(x−aⱼ), B(x)=∏(x−bⱼ), H=A/B. Тогда

```math
\mu=\sqrt{1-H(e_2)/H(e_1)},\qquad L=1-\mu,\quad U=1+\mu,
\quad c=\frac{1}{U H(e_1)},\qquad
r(x)=\frac{L B(x)-c U A(x)}{B(x)-c A(x)}.
```

Для получения второй дроби возьмём r*=(1−μ²)/r. Обе дроби имеют максимальную ошибку μ на четырёх полосах.

## Почему формула работает

1. Из чередования a₁<b₁<a₂<b₂<a₃<b₃ все вычеты H в bⱼ положительны. Поэтому H убывает на каждой непрерывной вещественной ветви. Слева от a₁ функция H положительна и H(e₁)>H(e₂)>0. Следовательно, 0<μ<1.
2. На каждой полосе пропускания H убывает от 0 до −∞. Дробь r монотонно возрастает от L до U. На [e₁,e₂] величина cH убывает от 1/U до L, поэтому знаменатель в выражении (L−cUH)/(1−cH) положителен. Подстановка даёт r(e₁)=−U и r(e₂)=−L. В представлении через A,B значения в bⱼ вычисляются без предела. Общих корней у числителя и знаменателя нет, проектная степень равна 3.
3. Ошибки r на восьми концах по порядку равны −μ,+μ,−μ,+μ,−μ,+μ,−μ,+μ. Для любой близкой дроби степени ≤3 знаменатель можно выбрать с прежним знаком на каждой полосе. Если бы её ошибка была строго меньше, числитель разности двух дробей менял бы знак семь раз. Его степень не превосходит шести. Это доказывает локальную оптимальность и исключает строгое улучшение во всём классе с теми же знаками знаменателя. Для r* чередование начинается с противоположного знака. При сравнении разных классов могут получаться другие значения ошибки.
4. Дробь H имеет три простых прообраза любого вещественного проектного значения. Это следует из положительных вычетов и строгой монотонности на трёх промежутках проектной прямой между полюсами. При H=1 один из простых прообразов — бесконечность, поскольку коэффициент при 1/x в разложении H ненулевой. То же верно для r как дробно-линейной функции H. Четыре уровня V={−U,−L,L,U} дают 12 различных точек ветвления нормализации y²=∏(r(x)−v), v∈V. По Риману–Гурвицу её род равен (12−2)/2=5. Чтобы вычислить саму дробь в этом семействе, достаточно рациональной формулы.

## Точный пример

При e=(−4,−3,−2,−1,0,1,2,3) получаются H(e₁)=16/35, H(e₂)=5/16, μ=9/16, c=7/5. Здесь A=(x+2)x(x−2), B=(x+1)(x−1)(x−3). На первой полосе r возрастает от −25/16 до −7/16, а на каждой из трёх следующих — от 7/16 до 25/16.

```julia
using StiefelFourBands
f = cubic_fourbands([-4,-3,-2,-1,0,1,2,3])
plot_filter("cubic.html", f)
```

Степень фиксирована. Семейство рода 3 с двумя разрезами и семейство рода 5 могут дать разные локальные решения на одном и том же наборе полос. Для заданной большей степени остаются отдельные конструкции и общая задача минимизации по классам. [Обзор других режимов](other_genera.md)
